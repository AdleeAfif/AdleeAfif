# 💫 About Me

👋 Hey, I'm **Adlee**, a **Cloud Native Engineer at Lenovo** based in Malaysia.

☁️ I build the backend of a cloud GPU orchestration platform that provisions, schedules and tracks AI workloads on **Kubernetes**, using **Java (Spring Boot)** and **Go**. Day to day that means Rancher/RKE2, Helm, GitLab CI, and observability with VictoriaMetrics, Grafana and NVIDIA DCGM.

👨‍💻 Before that, I was a backend engineer at **TM R&D**, where I built **NestJS** microservices and a **RabbitMQ** backbone for 100+ asynchronous workflows on live telco systems. I care about how systems behave in production (auth, caching, retries, rate limiting), not just in local development.

🏠 At home I self-host on a **Raspberry Pi 5** running **k3s** behind a Cloudflare Tunnel, with images shipped through GitHub Actions.

🏅 Google Cloud Associate Cloud Engineer · AWS Certified Cloud Practitioner · BCS (Software Engineering) Hons, UMPSA

🎮 Outside of work: comics, gaming and sci-fi.

📫 Reach me at **`adlee.afiff@gmail.com`**. Always happy to talk backend, platform engineering, or side projects 🚀
